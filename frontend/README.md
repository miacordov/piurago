# PiuraGo - Frontend

Aplicación Flutter (móvil y web) de PiuraGo. Mapas con flutter_map + OpenStreetMap.

## Requisitos

- Flutter SDK, canal stable. Verifica con `flutter doctor`.
- Chrome, para probar la versión web.

## Ejecutar

    cd frontend
    flutter pub get
    flutter run -d chrome

## Análisis y pruebas

    flutter analyze
    flutter test

## Referencia de diseño

Ver `docs/diseno/`. El prototipo de Lovable es solo referencia visual: no se reutiliza su código.
